# v2.19 (2026-11-25)

## 🩹 軽減表: ジョブ名・アビリティ名の行をシートで隠していても、列の名前と担当ジョブを読めるようにした (「自分の担当だけ」の絞り込みが効くように)

### 狙い

実機確認待ちの L-8 (軽減表の列ラベルの括弧の中のジョブ名が読めるか) を、本番の「絶もうひとつの未来」の実物のシートで確かめたところ、チェック列 29 本の自動ラベルも、列 → ジョブの対応も 0 本だった。手で名前を登録していなければ、カードの「自分の担当だけ」の絞り込みが効かない。

原因: 通常の共有 URL は gviz (`/gviz/tq?tqx=out:csv`) で CSV を取っていて、**gviz の CSV はシートで隠した行を落とす**。このシートはジョブ名・アビリティ名・対象種別の行 (2〜5 行目) を隠していた。同じシートの `/export?format=csv` は隠した行も含めて全 82 行が入る (gviz は 54 行)。

### 実装

- カードに出す行は今までどおり gviz から取る (隠した行は出さない)
- 表示中の表から見出し行が見つからず、チェック列があるときだけ、全行の表 (`/export?format=csv`、`toSheetExportCsvUrl`) を取る。`*.googleusercontent.com` へ 1 段リダイレクトするが、`safeFetch` が段ごとに検査する。シートの表と同じく Upstash の自前の SWR に置く (`fetchSheetFullGrid`)
- **列の並びが表示中の表と揃っているときだけ** (`sameColumnLayout`: 表示中の表のデータ行の 8 割以上が、全行の表に同じ並びで在る) そこから見出し行を探し、列ラベルを作る。揃っていなければ今までどおり
- 公開 (`pubhtml`) の URL は対象外 (今までどおり)

### 検証

- 本番の実物のシートを、軽減表のページと同じ順の関数に通した: 見出しの出どころが export になり、チェック列 29 本すべてにラベルとジョブ (ナイト 6・暗黒騎士 5・賢者 8 ほか計 8 ジョブ)。gviz の 53 行中 52 行が export に同じ並びで在り、export を 1 列ずらすと 0 行
- `check-ability-header.mjs` に、export の URL (gid・pub・別ホスト)、実物の形を縮めた表での通し (gviz では見出し無し → export で見つかる)、列の並びの判定 (1 列ずれ・別シート・空・75% / 80% の境目)、ページの配線を足した。ページの変更を外すと配線の 3 件が落ちる
- `tsc` / `eslint` / `scripts/check-*.mjs` が通る

### 動作影響 / トレードオフ

- 見出し行を隠しているシートでは、初回の表示でシートの取得が 1 回増える (以降は保存先から読む)
- 手で登録した列の名前は、今までどおり自動の名前より優先する
