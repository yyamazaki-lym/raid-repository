## 🏷 軽減表: アビリティ名の設定を作り直し

シートのアビリティ欄は**アイコン画像**で作られており、Google Sheets の CSV には画像が一切出力されません。つまり列の正体を機械的に知る方法が無いため、名前は手で付けていただく必要があります。その入力を最小の手間で終えられるよう作り直しました。

- **どの攻撃でチェックされているかを各列に表示**します。「キング・オブ・アルカディア / ウェポンアサルトで ON」と見えるので、列の正体 (牽制など) を推測できます
- 列は **ON が多い順**に並べ、名前を入れた列は緑になるので残りが一目で分かります
- よく使う軽減名は**入力候補**から選べます
- **まとめて入力** (`DO=牽制` の形で貼り付け) にも対応
- 判定結果の表は畳んでおき、必要なときだけ開く形に

名前を付けると、カードの**種別の横に ✓ 付きで並びます**。

## ✔ 軽減表: 入れるアビリティを種別の横に表示 + 英語表記の日本語化

**アビリティ名を自動で拾えるようにしました**。軽減表テンプレートは「見出し行にアイコン → その下の行にアビリティ名」という 2 段組みが多く、CSV ではアイコン行が空になるため名前が取れていませんでした。**アビリティ名が書かれている行を自動検出**して見出しの代わりに使います (その行自体はカードにしません)。

拾えたアビリティは**種別 (Type) と同じ行にチェック印つきで表示**します。「この攻撃で何を入れるか」が 1 行で読めます。自動で拾えないシートは、これまでどおり「列の設定」から名前を登録できます。

あわせて **Calculate Mitigation / Damage / Magic といった定型の英語を日本語表記**にしました (軽減計算 / ダメージ / 魔法)。技名や担当者名など固定ごとに自由に書かれる文字列は、勝手に訳すと原本と食い違うため touch していません。

「列の設定」ダイアログが見切れていたのも直しました (幅を広げ、横スクロールは表の中だけに閉じ込め)。

## 🔧 軽減表: 数値ラベルをシートの列名に + 列の設定/診断を追加

**「軽減率が 2 つ並んで分かりにくい」の修正**: チップのラベルに、こちらで決めた種別名 (ダメージ/軽減率/最終) ではなく**シートの実際の列名**を出すようにしました。別の列が同じ名前で並ぶことがなくなります (色は種別のまま: 赤=素ダメージ / 青=軽減率 / 緑=最終)。同じ列名・同じ値の重複も畳みます。

**「Type と軽減率以外は情報が出ない」への対応**: 軽減表のチェックボックス列は、見出しがアイコン画像だと CSV に文字が 1 つも出ないため名前が分からず、これまで表示を諦めていました。カード上部に**「列の設定」**を追加し、

- アプリが各列を**どう判定したか**の一覧 (列記号・見出し・判定・中身の例) を表示
- **チェック列に名前を付ける**と、その名前でカードに表示 (層ごとに登録)

これで「なぜ出ないのか」をシートを開かずに切り分けられ、名前を付ければ「この攻撃で入れる軽減/バフ」が並ぶようになります。

## 🗑 練習ログ: 誤って取り込んだレポートを削除できるように

ノーマルなど**別のコンテンツのレポートを取り込んでしまったとき、練習ログから削除できる**ようにしました。日を開いた中のレポートコードの隣にゴミ箱があります。

削除するとその pull を消すだけでなく、**以後の同期でも取り込まなくなります** (動画リンクや日付ログからそのレポートが参照され続けている限り、消すだけでは次の同期で復活してしまうため)。

予防側として、ヘッダーの**「取り込み設定」**で**取り込む難易度の下限**を指定できます。FFLogs の難易度は数値で、コンテンツ種別によって値が変わり公開された対応表がないため、**取り込み済みの実測値 (難易度ごとの pull 数と技名)** を画面に出しています。それを見て残したい値を決めてください (推測で「ノーマルはこの値」と決め打ちすると、絶などを巻き添えに除外する恐れがあるため)。

## 🛡 軽減表: チェックの入ったアビリティを抜き出して表示

「誰がどのデバフ・バフを入れるか見えない」への対応です。軽減表でよくある**チェックボックス列**は CSV 上 TRUE/FALSE になるため、これまでカードから完全に消えていました。

**行でチェックが入っている列の見出し (アビリティ名) を抜き出して**チップで表示します。列見出しがアイコン画像だけで文字が無い場合は、その列に書かれているアビリティ名を拾って代用します。

担当のチップには**ロール色**を付けました (MT/ST = 青 / H1・H2 = 緑 / D1〜D4 = 赤)。ゲームのジョブアイコン画像は配布できないため、ロール色のバッジで代替しています。

## 🎨 練習ログ: 右側の層表記も色分け

日ごとの到達度の右側にある「1層」「4層後半」などの層表記にも、層チップと同じ色を当てました。行全体を見なくても、どの層まで行った日かが色で拾えます。

## 🚩 討伐したのにフラグが付かない不具合を修正

「討伐済みなのにフラグマークが出ていないことがある」の原因を特定して修正しました。

最終層が前半/後半に分かれるティアでは、**4層前半を討伐した日**もその日の最深層基準では「残 0%」になります。そのため記録の基準が先に 0% になってしまい、後日の**本当の初討伐**が「記録更新」と判定されずフラグが立ちませんでした。

「初めてクリアした日」は残% の比較とは無関係に記録として扱うようにし、初討伐のフラグは**緑**で表示して自己ベスト更新 (水色) と区別できるようにしました。

## 🗓 練習ログ: 日付クリックで振り返りへジャンプ / 4層前半・後半の色分け

**日ごとの到達度の日付をクリック**すると、その日のセッション振り返りが開いてスクロールします (折りたたみ中や層フィルタで隠れている日にも飛べます)。

**4層前半と後半を別の色**にしました (前半 = ローズ / 後半 = フクシア)。層フィルタも「4層前半」「4層後半」を個別に選べます。

また **Logs / 死亡 / 被ダメのリンクは日本語表示 (ja.fflogs.com) で開く**ようにしました (保存してある URL 自体は変更していません)。予定表の Logs アイコンも同様です。

## 📐 軽減表: 層タブの登録 + 担当をチップ表示

**「シートが一番最初のものしか参照されない」問題**に対応しました。ワークシート一覧の自動検出はシートの公開設定に左右されて当てにならなかったため、**層ごとの gid を登録する画面**を用意しました (カード表示の上の「層タブを設定」)。gid は Google Sheets で各シートのタブを開いたときの URL 末尾 `#gid=123456` の数字で、URL を丸ごと貼っても抽出します。登録すると層タブで切り替えられます。

また**「誰がどの軽減・バフを入れるか」**を追いやすくするため、担当の表示を「担当者: スキル」のチップに変え、1 つの攻撃の分担が数行で読めるようにしました。

## 🧩 BiS プレビューの揺れを修正 + 動画オフセットの自動登録

BiS の装備プレビューで**表示がブレる**問題を修正しました。読み込み前後で高さが変わらないよう枠を固定し、シート全体のリンク (複数セット) では「単一セットしか埋め込めません」と出ていたのを、1 セット目に絞って表示するようにしました。

また、**Logs と動画が紐づいている場合、動画オフセットの行を自動で作る**ようにしました (ログ同期時)。動画 URL だけ先に入るので、あとは秒数を入れるだけです (秒数は映像を見ないと決まらないため自動では入れません)。

## 🗺 ウェイマークの配置プレビュー

登録したウェイマークを開くと、**8 点の配置を真上から見た図**が出ます (北が上、A〜D は四角・1〜4 は丸で、ゲーム内と同じ色分け)。

アリーナの地形データは持っていないので、**描いているのは点の位置関係だけ**です (円や床のフチは描きません — それらしく描くと実際とずれたときに「合っている」と誤解させるため)。取り込める形式として認識できたものにだけ表示されます。

## 🧰 ポップアップの開閉挙動を統一 + 読みにくい文字の底上げ

画面内に手書きのポップアップが 3 つあり (日付メモ / スケジュールのルール / メンテナンス結果)、似たコードを写して持っていた結果、細かい挙動がばらついて不具合になっていました。共通化して次の 2 点を全部で揃えています。

- **再クリックで閉じる**: トリガーを「外側」と誤認して閉じられなくなる不具合の作り込みを構造的に防止 (ルールの不具合と同じ原因)
- **フォーカスを奪わない**: 閉じたときにフォーカスを戻すのは、他へ移動していない場合だけに統一 (メンテナンスメニューが操作中に勝手にフォーカスを奪っていたのを修正)

あわせて設定画面の状態表示 (ON/OFF や補足行) が 9px の最も薄い灰色で読みにくかったので、少し大きく・濃くしました。

## ✅ ウェイマークの形式チェック

貼り付けたウェイマークが**取り込める形式か**をその場で判定し、行に「取込可 8点」バッジを出します。編集ダイアログでも入力中に確認できるので、配ってから現地で「取り込めない」と気づく事故を防げます。

あわせて座標の粗いチェックも行い、**アリーナ外や空中を指していそうなプリセット**には「要確認」を出します (2022 年に問題になった、ツールで場外に置かれたマーカーの混入避け)。Waymark Studio の共有 URL を貼った場合は、ブラウザで配置を見に行くリンクが出ます。

## 🗓 予定を Google カレンダーへ + 全員入力で自動確定 (任意)

**次回開催日カード**にカレンダーアイコンを追加。1 クリックで Google カレンダーの追加画面が開き、スマホのカレンダーにも予定を置けます (22:00〜0:00 のような日跨ぎも正しく翌日終了になります)。

また、自前スケジュール (native) 向けに **「全員入力で自動確定」** をオプションで追加しました。候補日に全員が出欠を入れ、参加可能な人数が指定数以上になったら自動で確定に切り替えます。**既定は OFF** です。全員が「×」でも「全員入力済み」にはなってしまうため、必要な参加可能人数 (既定 8 人) を必ず併用する設計にしています。

## ⏰ 出欠の催促 — 未入力の人だけに自動メンション

開催予定日の指定日数前になっても出欠を入れていない人だけを、まとめて Discord でメンションする機能を追加しました (設定 → 「出欠の催促」)。

- **既定は OFF**。ON にするまで 1 通も送りません
- **何日前 / 何時 / 送信先チャンネル**を設定 (既定は前日 21 時、チャンネル未設定なら通常通知と同じ場所)
- **メンション先の登録**: 表示名 → Discord ユーザー ID の対応表。未登録の人は名前だけ本文に出ます
- **除外リスト**: 常に未入力のメンバーにチェックを入れると、催促にも集計にも出てこなくなります
- **「誰に飛ぶか確認」ボタン**で送信前に対象を確認でき、「今すぐ送信」でテストもできます

同じ開催日に二重で送らないようになっており、@everyone などは絶対に飛びません。

## 🗺 ストラテジーボードの共有コードを保管できるように

マクロタブのウェイマークの 1 つ上に「ストラテジーボード」を追加。パッチ 7.4 のゲーム内機能で発行できる共有コードを、ラベルを付けて保管 → ワンタップでコピーできます。

ウェイマークの上に置いているのは、共有コードが**プラグイン不要でコンソールからも取り込める**唯一の図面共有手段だからです (ウェイマークはゲーム内に共有機能が無く、取り込めるのは PC + プラグイン環境の人だけ)。ウェイマーク側の説明文も「1 人が取り込んで設置すれば全員に見える」前提に書き直しました。

## 🔍 練習ログから死亡 / 被ダメへ直行 + 攻略リンクに種別バッジ

**練習ログの各 pull 行**に、FFLogs の「死亡一覧」と「被ダメージ」へ直行するボタンを追加 (Logs ボタンの隣にアイコンで連結、行は伸びません)。「この wipe は何で死んだか」を 1 クリックで見に行けます。

**攻略情報のリンクカード**には、既知の FF14 サイトなら種別バッジを表示 (攻略 / 野良主流 / ログ / 装備 / シム / 作図)。ゲーム8 や Materia Raiding は「攻略」、ふうcだよや wtfdig は「野良主流」、xivgear は「装備」… という具合に、見る目的で分けられます。

## 🎨 練習ログの配色改善 — 層の識別色と残%の熱量色

実機報告「文字が灰色だらけで見にくい。PC から見ると若干小さい」への対応。

- データ行の文字を 10px → 11px に、サマリカードの数値も PC で一回り大きく
- **層チップに識別色**: 1層=空色 / 2層=青緑 / 3層=紫 / 4層 (前半/後半とも)=ローズ / 複数層の日 (1-4層 等)=シアン
- **残% を値で色分け**: 討伐=緑、残2%未満=ローズ (激惜)、〜10%=オレンジ、〜30%=琥珀、〜60%=空色、それ以上=従来のグレー。ボス HP が減るほど熱くなる直感に合わせた
- pull 行は「層チップ + 結果チップ (CLEAR / 残%)」の 2 チップ構成に分離し、ひと目で拾えるように

## 🛡 軽減表カードを簡素化 — ダメージ→軽減率→最終 + 層タブ

実機要望「AA を除く攻撃とダメージ値、入れる軽減・対象、軽減率と最終ダメージ値で簡素に。シートの各層を切り替えたい」への対応。

- **AA (オートアタック) 行はカード化しない**
- 見出しキーワードから **素ダメージ / 軽減率 / 最終ダメージ / 対象** の列を検出し、「ダメージ → 軽減率 → 最終」の色付き数値サマリ (赤→青→緑) と対象チップで表示。残りのセルは従来どおり「担当: 軽減スキル」
- **層タブ切替**: スプレッドシート内のワークシート (層) 一覧を自動検出し、カード表示の上にタブを表示。タブを押すとその層のシートに切り替わる (シート表示は Sheets 自身のタブバーをそのまま利用)

## 📋 ルールが再クリックで閉じない不具合を修正 + BiS を攻略情報へ

スケジュールの「ルール」ボタンは開けるのに再クリックで閉じられなかった (外側クリック判定がボタン自身を外側と誤認し、閉じる→即開くを繰り返していた)。日時クリックと同じトグル挙動に修正した。

あわせて **最適装備 (BiS) セクションをロット管理から攻略情報タブへ移動** (LINKS の上)。装備更新の参照とマクロ/リンク類を同じ画面で見られるように。
