## ⚠ 制約 (先行 TODO の教訓、違反禁止)

- **popover / tooltip / dropdown-menu への close transition 再追加禁止**: `popover.tsx` / `tooltip.tsx` / `dropdown-menu.tsx` の `data-closed:animate-out` / `data-closed:fade-out-0` / `data-closed:zoom-out-95` 系列は visual rebound + 本番 DOM 残留 (白枠) 再発のため再追加禁止 (TODO #65 part8 / #70〜#72 の経緯)。フェードアウトを入れたい場合は `duration-50` + opacity-only 版 (zoom-out なし) のみ可
- **初期 bundle を太らせない**: TODO #11/#67 で削った client bundle を polish で逆戻りさせない。skeleton は CSS-only、illustration 系は lucide icon 流用か `next/dynamic`、新規アニメライブラリ追加は不可 (framer-motion 既存分で賄う)
- **popover 系の新規実装は TODO #72 パターン必須**: `<Popover open={open} onOpenChange={setOpen}>` controlled + `{open && <PopoverContent finalFocus={false}>}` unmount
