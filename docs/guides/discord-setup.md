# Discord の推奨構成と Webhook / Bot 設定手順

最終更新: 2026-09-07 (W-34)

portal は Discord をログイン基盤と情報の入口として使う。**導入時に何を作れば
よいか**をこの 1 枚に集約する。

## 前提

- portal のログインは **Discord OAuth + サーバー(guild) メンバーシップ**で
  ゲートしている。指定の guild に居ない人は入れない。
- 攻略リンク / 動画は **Discord のチャンネルから自動取り込み**できる。
- 通知 (開催確定・出欠催促・練習ログのイベント) は **Bot がチャンネルへ投稿**
  する。

## 推奨チャンネル構成

最小構成は 4 つ。既にサーバーがあるなら無理に作り直さず、役割が近い
チャンネルの ID を設定に入れれば足りる。

| チャンネル | 用途 | portal 側の設定 |
|---|---|---|
| `#攻略情報` | 攻略サイト・散開図・タイムラインの URL を貼る | コンテンツ編集の「攻略ch ID」 |
| `#動画` | 練習動画・クリア動画の URL を貼る | コンテンツ編集の「動画ch ID」 |
| `#連絡` | 開催確定 / 出欠催促 / 練習ログの通知が飛ぶ | 設定の「Discord 通知」チャンネル ID |
| `#雑談` | portal は触らない | — |

### 分け方の指針

- **攻略と動画は分ける。** portal はチャンネル単位で取り込むので、混ざって
  いると攻略タブに動画が並ぶ (フィルタキーワードで絞ることもできるが、
  分けるのが確実)。
- **通知先は 1 つに寄せる。** 開催通知・出欠催促・練習ログ通知はすべて
  同じチャンネル設定を使い回している。分けたい場合は出欠催促だけ別 ID を
  指定できる。
- **コンテンツごとにチャンネルを分ける必要はない。** 取り込みは
  コンテンツ単位でキーワードフィルタを掛けられるので、`#攻略情報` 1 つで
  複数コンテンツを回せる。

## チャンネル ID の取得

1. Discord の設定 → 詳細設定 → **開発者モード**を ON
2. チャンネルを右クリック → **「チャンネル ID をコピー」**
3. portal の設定 / コンテンツ編集の該当欄に貼る (18〜19 桁の数字)

## Bot の権限

通知と取り込みに必要な権限は次のとおり。**管理者権限は不要**。

| 権限 | 何に使うか |
|---|---|
| メッセージを読む / 履歴を読む | 攻略・動画チャンネルからの取り込み |
| メッセージを送信 | 開催通知 / 出欠催促 / 練習ログ通知 |
| メンション | 出欠催促 (未入力者に飛ばす場合のみ) |

- Bot を招待したあと、**対象チャンネルで Bot が見える**ことを確認する
  (プライベートチャンネルは個別に権限を付ける必要がある)。
- 練習ログの通知は**メンションを使わない** (見に来る動機を作るのが目的で、
  全員を叩き起こすものではない)。出欠催促だけがメンションする。

## 出欠催促のメンション設定

催促は**既定 OFF**。ON にする前に次を決める。

1. **送信先チャンネル** (未設定なら開催通知と同じチャンネル)
2. **何日前・何時に送るか** (既定は前日 21:00 JST)
3. **頻度** — 「期限に 1 回」(既定) / 「期限 + 当日」/ 「毎日 1 回」
4. **表示名 → Discord ユーザー ID の対応表** (メンションに必要)
5. **除外する人** (常に未入力でよいメンバーを静かに外す)

メンションは実在の人に直接飛ぶ副作用なので、**「プレビュー」で誰に飛ぶかを
確認してから ON にする**こと。

## 練習ログの通知

**すべて既定 OFF。** 種類ごとに ON にする。

| 種類 | 頻度の目安 |
|---|---|
| 新しいレポートの取り込み | 練習した日ごと (最も多い) |
| ベスト到達の更新 | 進捗があった日だけ |
| 初討伐 | コンテンツごとに 1 回 |

通知が多いと読まれなくなるので、**まず「初討伐」だけ ON** にして様子を見る
のがおすすめ。

## よくある詰まり

| 症状 | 原因と対処 |
|---|---|
| ログインできない (`/auth/denied`) | 指定 guild に居ない。招待を確認 |
| 取り込みが 0 件 | チャンネル ID が違う / Bot がそのチャンネルを見えていない |
| 通知が飛ばない | 通知先チャンネル ID 未設定、または Bot トークン未設定 |
| 催促が飛ばない | 既定 OFF のまま / 目標時刻前 / その日は送信済み |
| 動画が攻略タブに出る | 攻略chと動画chが同じ。チャンネルを分けるかフィルタを設定 |
