# v2.19 (2026-11-22)

## 🩹 動画: 「日付順」を題名の日付 (無ければ公開日時) の新しい順にした。取り込み直した動画が古い日付でも先頭に来ていたのを直した

### 狙い

2026-11-22 の実機報告: 再生リストから取り込んだ動画を消して YouTube 側で題名を直し、取り込み直したところ、「FINAL FANTASY XIV 絶エデン2026 11 14 PART23」が 11/20 の動画より上 (一番上) に出た。「メタ情報を取得」をしても並びが変わらなかった。

動画タブの「日付順」は、題名の日付でも公開日時でもなく **行の作成日時** (`created_at`) の新しい順で並べていた。取り込み直した行は今日作られるので、練習日が古くても先頭に来る。メタ情報の取得は長さ・公開日時を埋めるが、並びの鍵ではなかった。

### 実装

- `sortVideosNewestFirst` (`src/lib/video-challenge-time.ts`、純関数): 練習日 (題名の日付 > 投稿日時の JST 暦日 > 行の作成日時。挑戦時間の集計の `videoDayNumber` と同じ順) の新しい順。同じ日は投稿日時 → 作成日時の新しい順、最後に `sort_order`。日付の読めない行は下にまとめる
- 動画タブ (`videos-list.tsx`) の「日付順」をこれで並べる。カスタム順 (並べ替えた順) は変えない

### 検証

- `check-video-challenge-time.mjs` に、本番の 4 本の形 (取り込み直した PART23 / PART25 と Discord の DAY 24 / DAY 25)、題名に日付の無い行、同じ日の並び、日付の読めない行、配列を書き換えないこと、と配線 (作成日時だけで並べない) を足した。画面側の変更を外すと配線の検査が落ちる
- 手元の dev で、デモの「絶もうひとつの未来」に取り込み直しの形の行 (作成日時・公開日時が今日、題名が 2026 01 20) を一時パッチで足して表示を比べた。直す前は先頭、直した後は 1/28 と 1/14 の間に出た (パッチは戻した)
- `tsc` / `eslint` / `scripts/check-*.mjs` が通る

### 動作影響 / トレードオフ

- 既存の並びも変わる: 題名に日付のある動画は題名の日付順になる (今までは取り込んだ順)
