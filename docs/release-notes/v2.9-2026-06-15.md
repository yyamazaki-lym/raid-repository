## 🗓 スケジュールの「自前作成式」を正式メニューに格上げ (準備中表記を解除)

設定 → スケジュールソースモードの「自前作成式」に付いていた「(準備中)」表記を外し、正式な選択肢にした。候補日の追加・出欠入力・開催確定・FFLogs 連携・Discord 通知まで portal 内で完結する自前スケジュール機能が一通り実用レベルに達したため。

デフォルトは従来どおり「同期式 (既存)」のままで、本番のスケジュール表示挙動は変わらない (admin が設定で「自前作成式」に切り替えた場合のみ、portal 内で作成したスケジュールが表示される)。今回はメニュー上の表記更新のみで、機能そのものの変更はない。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。dev preview で設定ダイアログのソースモード欄に「自前作成式」が準備中表記なしで表示されることを確認。

## 🚫 Discord 自動取り込みで特定の動画を「今後取り込まない」除外機能

Discord から自動取り込みされる動画 / 攻略リンクのうち、不要なものを今後取り込まないよう除外できるようにした。動画・攻略リンクの ⋮ メニューに「今後取り込まない」を追加 (Discord 取り込み分のみ)。選ぶとそのリンクを削除し、以後の自動取り込みでもその URL をスキップする。

これまでは削除しても元の Discord メッセージが残っていると翌日の自動取り込みで復活していたが、除外した URL は確実にスキップされる。除外した URL はコンテンツ編集ダイアログの「取り込み除外 URL」から確認・解除できる (解除すると再び取り込み対象に戻る)。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。schema (除外リスト用テーブル) は本番 / demo に自動デプロイ。dev preview で ⋮ メニューと編集ダイアログの UI 描画を確認。

## 🟢 ヘッダーの「ONLINE」表示が実際のオンライン人数を示すように

これまで常時点灯の飾りだったヘッダー右上の「ONLINE」を、いま同じポータルを開いているメンバーの人数表示に変更 (総合レビュー F-4)。Supabase のリアルタイム機能 (presence) を使い、接続中のメンバー数を「ONLINE 3」のように表示する。同じ人が複数タブで開いても 1 人として数える。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。dev preview でヘッダーが自分 1 人のとき「ONLINE 1」と表示されること・コンソールエラーが無いことを確認 (人数はリアルタイム接続中のメンバー数に追従)。
