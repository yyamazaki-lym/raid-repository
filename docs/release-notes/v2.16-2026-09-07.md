# v2.16 (2026-09-07)

## 🐛 練習ログ: 拡張をまたいだ絶 (Ultimates (Legacy)) のレポートが取り込めなかったのを修正 — pull の encounter 名で振り分け

**実機報告**: 絶オメガ検証戦の練習ログが 2024-06-18 で止まり、FFLogs 側にある 2024-07 以降のレポート (Dawntrail 期) が取り込まれない。「分類が拡張ごとに違っているのでは」という指摘どおりでした。

**原因**: FFLogs の zone は拡張ごとに切り直され、旧拡張の絶は現行拡張では **"Ultimates (Legacy)" という 1 つの zone** にまとめられます (絶バハ / 絶アルテマ / 絶アレキ / 絶竜詩 / 絶オメガがすべて同じ zone)。レポートのタイトルも「絶シリーズ（過去）」のように何の絶か書かれません。portal のカテゴリ判定は **レポート単位** の zone 名 / タイトルしか見ていなかったため、こうしたレポートは「カテゴリ未確定」のまま、どの練習ログにも出ませんでした。

**修正**: fight (pull) には encounter 名 ("The Omega Protocol" / "Dragonsong's Reprise" など) が付くので、**fight ごとに** encounter 名をコンテンツ分類器に通してカテゴリを決めるようにしました (`src/lib/fflogs-category.ts` に純関数として切り出し)。優先順位は「fight 名で一意に決まるカテゴリ → レポート単位の解決 (zone ID / zone 名 / タイトル) → 動画リンク由来」。同じ夜に 2 種類の絶をやったレポートも、それぞれのカテゴリへ振り分けられます。レポート台帳の代表カテゴリは fight の最多で決めます。零式の fight 名はボス名なので分類器に当たらず、従来どおりレポート単位の判定です。

- **既に取得済みで未確定のレポート**: 次の同期の「オフライン再解決」で、保存済みの fight 名から fight ごとに再分類します (FFLogs は叩きません)。絶オメガの 2024-07 以降がこれで出るはずです。
- 取り込み難易度の下限 (`fflogs_min_difficulty`) も fight ごとのカテゴリで判定します。
- `expected_fflogs_zone_ids` に Legacy zone を複数の絶カテゴリへ設定していても (= レポート単位では曖昧) fight 単位で決まります。

**検証**: `scripts/check-fflogs-category.mjs` (新規、13 ケース: Legacy zone + 汎用タイトルは決められない / fight 名で決まる / 零式ボス名は決まらない / 代表カテゴリ) と `tsc` / `eslint` / `check-changelog`。実機では **次回同期後に絶オメガの 2024-07〜2025-01 のセッションが並ぶこと** を確認してください。出ない場合、そのレポートが portal に未登録 (動画にも日程ログにも URL が無い) の可能性があるので「URL から取り込む」に貼ってください。

## ⏱ 練習ログ: フェーズ滞在時間を「表示中の pull」ではなく登録ログ全件で集計

**実機報告**: 絶竜詩戦争 (1047 pull) の「フェーズ滞在時間」が「合計 … (表示中の分)」で、直近 1000 pull だけの集計になっていた。

**修正**: 明細 (最大 1200 件) とは別に、開始 / 終了 / フェーズ遷移 (jsonb) の軽い列だけを 1000 件ずつ全件読み、サーバー側で合計する `fetchCategoryPhaseTotals` を追加しました (`src/lib/supabase/fflogs-fights.ts`)。絶のページでは明細と並列に取得し、カードは全件の合計を「合計 … (登録ログ全 N pull)」と表示します。N はフェーズ遷移が保存されている pull 数 (= 合計の母数) で、遷移が入っていない古い同期分は含みません。取得に失敗したときは従来どおり表示中の明細から計算します。

pull ごとのフェーズバーと「ワイプ原因」カードは従来どおり表示中の明細に基づきます (ワイプ原因は死亡イベント列を全件読む必要があり別途)。

**検証**: `tsc` / `eslint` / `check-changelog`。Supabase が無いため実描画は未確認で、実機で絶竜詩のカードが「登録ログ全 N pull」表記になり合計が伸びることを確認してください。
