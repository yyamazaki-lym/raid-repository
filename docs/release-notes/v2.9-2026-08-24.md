## 🗑 実施しなかった日を過去ログから消せるように

「実際には活動しなかったが、取り消しを忘れたために記録として残ってしまった日」を、過去ログから消せるようにした (管理者のみ)。

スケジュールページの過去ログ (詳細の出欠表) の日付の横にゴミ箱アイコンが出るので、押して確認すればその日が過去ログから消える (簡易の日付チップはスペースが限られるため対象外)。これまでは設定ダイアログの「DB の保存件数」に出る直近 20 件からしか消せず、しかも消しても翌日の自動保存や Discord 取り込みで同じ日が復活することがあった。

消し方は運用モードで自動的に切り替わる:
- 連携式 (character-sheets): 「実施しなかった日」の印を付けて非表示にする。出欠のスナップショットと FFLogs の URL は消さずに残すので、自動取り込みやスナップショットで復活することもない
- 自前作成式: その日程を「中止」にする (出欠の記録は残る)

間違えて消した場合も元に戻せる。連携式は設定ダイアログの「過去ログから除外中の日程」ボタンから一覧を出して ↺ で復帰、自前作成式は従来どおり「中止した日程」セクションから復帰できる。除外中の日付には FFLogs の自動紐づけも行われない。

初回リリース直後の実機フィードバック 2 点も同日中に修正: 削除後に「スケジュール取得失敗」が一時表示され反映も遅かった件 (削除処理が連携サイトの再取得を巻き込んでいたのを解消し、削除は DB 更新のみで即反映されるように) と、簡易チップ側のゴミ箱でチップが 1 行に収まらなくなる件 (詳細表のみに変更)。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。除外→解除の実データ往復は本番で確認。
