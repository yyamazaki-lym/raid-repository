## 🔗 日付から登録した FFLogs ログが同じ日の動画にも表示されるように

スケジュールの日付から手動で登録した FFLogs レポート URL が、同じ日の動画カードの FFLogs バッジには反映されない不具合を修正。

これまで FFLogs の URL は「日付に紐づくログ」と「動画に紐づくログ」が内部的に別管理で、日次の自動連携だけが両方へ反映していた。日付から手動で登録した分は日付側にしか入らず、動画一覧のバッジには出なかった。今後は日付からログを登録すると、同じ日 (日本時間) の動画にも自動でバッジが付く (すでにログが付いている動画は上書きしない)。登録したログを日付側から削除すると、その動画のバッジも一緒に外れる。

また、動画があとから (Discord 取り込みなどで翌日に) 追加されたケースや、この修正より前にすでに登録済みのログも、毎晩の FFLogs 自動連携が同じ日の動画へ後追いで反映する (設定画面の「FFLogs と動画を連動」を手動で実行しても同じ)。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。日付登録→動画バッジ即時表示、削除→バッジ解除、自動連携での後追い反映は実機で確認。
