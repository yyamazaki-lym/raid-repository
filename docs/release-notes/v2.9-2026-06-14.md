## 🛠 日付まわりの細かな不具合修正 — クリア日ジャンプのタイムゾーン依存 + 動画日付の誤判定

総合レビューで見つかった日付処理の軽微な不具合 2 件を修正 (実害は限定的だが正確性を底上げ)。

- **クリア日ジャンプのタイムゾーン依存を解消**: クリア日バッジ (🏆) をクリックして「その日の動画」へスクロールする機能が、日本以外のタイムゾーンのブラウザだと 1 日ずれて該当動画を見つけられないことがあったのを修正。クリア日の表示・最終同期時刻の表示も含め、日付は常に日本時間 (JST) の暦日基準で揃うようにした (日本在住の利用では従来どおりで見た目の変化なし)。
- **動画タイトルからの日付自動抽出を厳格化**: 「2月31日」「4/31」のような実在しない日付を誤って拾うことがあったのを修正 (うるう年の 2/29 も正しく判定)。FFLogs 自動リンクや初クリア日の推定に使われる。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。日付ロジックを単体検証 (America/New_York タイムゾーンでもクリア日が JST 暦日で正しく一致することを確認)。

## 🔧 ドラッグ並び替えの「一瞬だけ古い順に戻るちらつき」を解消 + 内部共通化

コンテンツ・動画・攻略リンク・攻略画像・マクロ・募集文テンプレートなど、ドラッグ&ドロップで並び替えできる各所の挙動を改善。

- **ちらつきの解消**: 並び替え直後に内部で「1.5 秒固定タイマー」で楽観表示を畳んでいたため、サーバー反映が遅れると一瞬だけ古い順に戻って見えることがあった。これを「サーバー確定値が新しい順に追いついたら畳む」方式に統一し、ちらつきと巻き戻りを解消。
- **内部共通化**: 6 ファイルにコピーされていた並び替え処理を共通フック (`useSortableReorder`) に集約し、保守性を向上 (見た目・操作は不変)。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。並び替えロジックを単体検証 (確定値が追いつくまで楽観表示を保持し、追いついたら畳む / 並行追加・削除にも安定)。dev preview で各リストの描画・募集テンプレ popover の並び替え UI を確認。

## 📝 日付メモを管理者以外のメンバーも編集できるように

スケジュールの各日付に紐づく「共有メモ」(日付クリックで開くポップアップ) を、これまで管理者しか保存できなかったのを、ログイン済みメンバーなら誰でも作成・編集・削除できるようにした。元々「全員が書ける共有メモ」という設計意図だったが、DB の権限設定 (RLS) が管理者限定のままでコメントと食い違っていたのを、設計意図に合わせて揃えた (総合レビュー A-4)。

- 未ログインの閲覧者 (公開デモのゲスト等) は従来どおり閲覧のみ。
- 本番サイトはログイン必須のため、実質「メンバー全員が編集可」。
- 所有者の区別が無い共有メモなので、メンバーは誰のメモでも編集できる (`お名前` 欄は表示用)。

**検証**: DB 権限設定 (RLS) の追加。merge 時に本番/demo へ自動適用 → 反映後に権限ポリシーの存在を SQL 確認。現状ポリシーが「読み取り=全員 / 書込=管理者のみ」であることを事前に本番 DB で確認済み (新ポリシーは追加のみ・anon は読み取り専用維持)。tsc/eslint/build pass。

## 💬 削除などの確認ダイアログをサイト統一デザインに

カテゴリ・リンク・動画・マクロ・募集文・攻略画像の削除や、サインアウト・各種クリア操作などの確認を、これまでブラウザ標準の確認ダイアログ (`window.confirm`) で出していたのを、サイトのテーマに沿った統一デザインのダイアログに置き換えた (総合レビュー F-4、計 14 箇所)。

- 取り消せない操作 (削除など) は実行ボタンを赤系で強調し、初期フォーカスをキャンセル側に置いて誤クリックを防ぐ。
- Esc / × / 外側クリックでキャンセル。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。dev preview でカテゴリ削除の確認ダイアログ表示 → Esc / キャンセルで実削除されないこと・console error 0 を確認。

## 🔤 日本語ラベルのフォントを統一 — レトロ等幅+広い字間は英字専用に

ナビタブ・ボタン・見出し・ステータスバッジなどサイト各所の日本語ラベルに、等幅フォント (mono) + 大文字化 + 広い字間が掛かっていて、かな漢字が不自然に間延びして見えていたのを、日本語は通常のゴシック体 (sans) + 通常字間に統一した (総合レビュー F-1、portal 全体)。

- 英字ラベル (CONTENTS / ONLINE / FFLogs / slug 等) や数値・日付・時刻のデータ表示は、これまでどおり等幅のレトロ表示を維持。
- ステータスバッジ (未着手/練習中/クリア済/休止中) の文字を 9-10px → 11px に底上げして読みやすく。
- 内部規約: globals.css にタイポグラフィ規約 (最小 11px の床 + 等幅は英字専用) を明文化。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。dev preview で /category・スケジュール・設定ダイアログの日本語ラベルが sans、英字/数値が mono のまま描画されることを実測・console error 0。

## 🎨 ステータス色を内部トークン化 + カテゴリ名を強調

コンテンツのステータスバッジ (未着手/練習中/クリア済/休止中) の色を、各所に直書きしていた色指定から共通のセマンティックカラー (globals.css の `--color-status-*`) に集約 (総合レビュー F-1)。見た目・意味 (emerald=クリア済 等) は変えず保守性を向上。意味色なので 7 テーマ切替でも一定 (信号機的な分かりやすさを優先)。

- カテゴリカードの第 1 階層であるコンテンツ名を太字 (medium) にして、右側の小さなメトリクス (クリア日 / 時間 / 取り込み数) との階層差を明確化 (F-4)。サイズは据置で長い名前の折り返しは発生しない。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。dev preview で 4 ステータスが正しく別色 (emerald/amber/gray/slate) で解決・コンテンツ名が 1 行のまま太字化・console error 0 を確認。
