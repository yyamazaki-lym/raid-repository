## 🩹 軽減表: ✓FALSE というチップが出るのを修正

チェック列の名前を「アビリティ名の行」から取る際、**その値が TRUE/FALSE でないかを確認していませんでした**。名前が書かれていない列ではその行にも真偽値が残っているため、そのまま `✓ FALSE` というチップになっていました。

ラベルは人が読むものなので、**真偽値・数値・極端に長い文字列は採用しない**ようにしました。名前が取れない列はチップ自体を出しません (意味の無い印を並べるより、出さない方が読めるため)。

手動登録に誤って `FALSE` が保存されている場合も同様に弾きます。以前の不具合で誤った名前を保存してしまった層の救済です。

## ⚠ 軽減表: 別の層の名前が入る不具合を修正 + 登録の削除

「チェックを入れていないはずのアドル (ピクトマンサー) が入る」の修正です。

**原因**: 真M12S-1 を開いているのに、別の層 (M10S) の見出しから名前を読み込んでいました。真M12S-1 は `BH` 以降が**1 列ずれた配置**なので、他の層の名前を当てると全部ずれます。実データでは 真M12S-1 の `EC` は「バマジク (赤魔道士)」ですが、M10S の `EC` は「アドル (ピクトマンサー)」でした。

**対応**: 内容照合で層を確定できても、**その層のチェック列と実際に重なっているか**を必ず裏取りするようにしました。列がずれていれば重なりが激減するので、そこで気付けます。食い違ったら確定を採用せず、どの層とどれだけ食い違ったかを「取得の詳細」に出します。

**既に保存された誤った名前**を消せるよう、設定に**「登録を消す」**を追加しました。登録は自動判定より優先されるため、消す手段が無いと直せませんでした。誤った名前が出ている層は、一度これで消してから読み取り直してください。

## 🐛 軽減表: 一部の列だけ名前が取れない不具合を修正

「CV のように一部取れていない」の修正です。**私の xlsx 解析のバグでした。**

シートの空セルは `<c r="CU4" s="53"/>` のように**自己終了タグ**で書かれます。これを開始タグと誤認して、**次のセルの中身まで飲み込んでいました**。そのため「空セルの直後にある列」だけ名前が読めず、実データでは CV (賢者/ホーリズム)、DL (モンク/牽制)、K (ナイト/リプライザル) の 3 列が欠けていました。

空セルを正しく 1 つのセルとして扱うようにし、提供いただいたシートで **22 列すべて**名前が取れることを確認しました。同じ書き方をする文字列テーブルの空要素も直しています (こちらは読み飛ばすと以降の名前が全部ずれる箇所でした)。

## 🔍 軽減表: 名前を xlsx から読み取り、層の特定を強化

「アイコンもアビリティもうまく出ない」「シートが多いと意図しない層が読み込まれる」への対応です。

**名前が出なかった理由**: 名前は 4 行目にありますが、Google の CSV 出力はチェックボックス列を真偽値の列とみなすため、そこに混ざる文字 (アビリティ名) を落としてしまいます。CSV からは読めなかったので、**xlsx から直接読む**ようにしました。「シートから読み取る」を押すと、ジョブ名とアビリティ名が `牽制 (忍者)` の形で入ります。**保存すれば以降は自動で表示**され、毎回押す必要はありません。

**層の取り違え**: M9S〜M12S-2 のように層が多いと、技名やジョブ名を大量に共有するため単純な一致率では差が付かず、隣の層を掴んでいました。**そのシートにしか出てこない語を重く見る**方式に変え、さらに CSV の中にシート名そのものが見つかればそれを優先します。どちらでも決まらないときは確定させず、「アイコン行」から手で選べます。

あわせて、カードに `無し` だけのチップが並んでいたのをやめました (担当なしを意味する値は表示しません)。

## ✅ 軽減表: アビリティ名を自動で表示 (手入力不要に)

実物のシートを解析したところ、**そもそもアイコンを解析する必要がありませんでした**。

26 行目のアイコンのセルは `=INDEX(Skill!$D:$D, MATCH(<その列>$4, Skill!$C:$C, 0))` という数式で、**「その列の 4 行目に書かれたアビリティ名」でアイコンを引いているだけ**でした。つまり名前はプレーンテキストで存在し、CSV にもそのまま出ています。

軽減表テンプレートは列ごとに 3 行の見出しを持っています。

- **3行目 = ジョブ名** (忍者 / 赤魔道士 …)
- **4行目 = アビリティ名** (牽制 / アドル …)
- **5行目 = 対象種別** (SELF / RANGE_PARTY …)

この 3 行を読んで、**チェック列に自動で名前とジョブを付ける**ようにしました。「アイコンから判定」を押す必要も、手で名前を入力する必要もありません。カードの種別の横に `✓ 牽制 (忍者)` のように並びます。

あわせて 2 点直しました。**見出しの 3 行はデータではないので、カードにも列判定にも混ぜません** (混ざるとチェック列が「文字列の列」と誤判定され、そもそも拾えませんでした)。また**チェックが 1 つも無い列は並べません** — 使っていないジョブの列も TRUE/FALSE を持つため、172 列の大半がノイズになっていました。

手動の名前登録は残してあり、シート側が空の列や、名前を変えたい列だけ上書きできます。

## 🎯 軽減表: 層に対応するシートを本文の一致で確定

アイコンの取得精度を上げました。

これまでは「タブ名で探す」→「チェック列との重なりで選ぶ」という当て方をしていましたが、隣接する層 (M12S-1 と M12S-2 など) は構成が似ているため取り違えが起きていました。

**表示中の層の CSV と、xlsx の各シートの本文を突き合わせて**、どのシートかを内容で確定させるようにしました。技名や時刻の並びは層ごとに違うので、名前や列の重なりで当てるより確実です。確定できた場合はそのシートの中だけからアイコン行を探すため、隣の層に引っ張られません。

隣接する層は技名を多く共有するので、**二番手と十分な差があるときだけ確定**します。曖昧なときは従来どおりチェック列の重なりで選び、その旨を「取得の詳細」に出します。一致率と次点の数字も出るので、当たっているかどうかが目で分かります。

## 🔧 軽減表: アイコンが隣のシートのものになる不具合を修正

「EA がズレる」「学者が取れていない」の原因です。

**原因**: xlsx の中でシート名と実データ (`sheet1.xml` など) を対応づける際、**ファイル名の番号順がタブ順と一致する前提**で組んでいました。実際の対応は関係定義 (rels) を辿らないと分からず、ズレると**アイコンが隣のシートのものとして扱われます**。開いているのが `M12S-2` なのに `裏M12S-1` のアイコン行が選ばれていたのはこのためで、列が食い違うぶんズレたり抜けたりしていました。rels を辿る正しい対応に直しました。

**選び直せるように**: 層 (gid) と xlsx のシートは機械的に結び付けられないため、自動選択が外れる可能性は残ります。**「アイコン行」の選択欄**を追加し、シート名・行番号・アイコン数・チェック列との一致数を見て選び直せるようにしました。選び直すと、前回の自動判定で入った名前だけが差し替わります(手で書いた名前は消えません)。

## 🛠 軽減表: アイコンが別シートのものになる不具合を修正

「S 列に詩人のアビリティが出る」「チェックされている攻撃が全く合っていない」の原因と対応です。

**原因**: 層の gid は xlsx に残らないため、登録した層タブ名 (「4-3」) で xlsx のシート名 (「M12S-2」) を探しに行っていました。名前が一致しないと**無関係なシートのアイコン行を掴み、列番号がまるごとズレます**。しかも黙ってそちらを使う作りだったため、誤りが表に出ませんでした。

**対応**: 名前ではなく、**そのシートのチェック列と重なる行**を選ぶようにしました。アビリティのアイコンはチェック列の真上にあるはずなので、重なりが最大の (シート, 行) が正解です。どの候補もチェック列と重ならない場合は**採用を見送り**、候補の一覧を「取得の詳細」に出します。黙って別のものを並べるより、見つからなかったと言う方が良いためです。

あわせて、Google の**「画像をセル内に挿入」で貼られたアイコン**にも対応しました。これは `=IMAGE()` 数式ではなく埋め込み画像なので、これまで取りこぼしていました。URL が残らないため名前の自動判定はできませんが、**アイコンそのものを表示**するので目視で名前を付けられます。

また、軽減表には TRUE/FALSE を持つ**非表示の計算列**が多く、チェック列を全部並べると無関係な列が大量に混ざります。アイコンが取れた列こそが本当のアビリティ列なので、**「アイコンのある列だけ」表示**に絞れるようにしました。

## 🖼 軽減表: アイコン取得を xlsx 経路に変更 + 失敗時の詳細表示

「アイコンから判定」が**取得できませんでした**になる件の対応です。

`=IMAGE()` のセルは、どうエクスポートするかで見えるものが変わります。

- **CSV / gviz** … 数式の*結果*が文字列化される → 空になる
- **HTML ビュー** … `<img>` で描画されるが、「ウェブに公開」が別途必要
- **xlsx** … `IMAGE("...")` と**数式が残る**。「リンクを知っている全員が閲覧可」だけで落とせる

当初は HTML ビューを見に行っていましたが、共有はしていても「ウェブに公開」まではしていないシートが多く、そこで失敗していました。**xlsx を第一経路に変更**し、HTML ビューは予備に回しました。xlsx には層 (gid) が残らないため、登録済みの層タブ名でシートを引き当てます。

あわせて、失敗したときに**どの経路で何が起きたか**を「取得の詳細」から見られるようにしました。共有設定なのか URL なのかシートの作りなのかを、これまでのように推測せず切り分けられます。

## 🖼 軽減表: アイコン画像からアビリティ名を自動判定

「アイコン画像は公式ジョブガイドの画像にリンクされている」という情報をもとに、**列のアビリティ名を自動で埋められるようにしました**。「アビリティ名」設定の「アイコンから判定」を押すと、

1. シートを CSV ではなく **HTML ビューで読む** (CSV は `=IMAGE()` の結果を文字列化するため空になるが、HTML なら `<img>` として出る)
2. アイコンが並んでいる行を見つけ、**列番号 → アイコン画像** を取り出す
3. 公式ジョブガイドのアクションアイコンと**画像のファイル名で照合**して名前を引く

という手順で、牽制・アドル・リプライザルなどの名前がそのまま入ります。既に手で入れた名前は**上書きしません**。

名前を引けなかった列でも、**アイコン画像自体を列の横に表示**します。見れば何の軽減かは分かるので、シートを開き直さずに名前を付けられます。

自動判定はあくまで**入力補助**です。公式サイトの HTML 構造に依存するため、先方の変更で引けなくなることがありますが、その場合も「判定できませんでした」と出るだけで、手入力の導線は常に残ります。
