# v2.18 (2026-10-21)

## 🩹 コンテンツ: 一覧のカードの大きさが揃わないことがあったのを直した (進行のスパークラインがあるカードだけ高くなり、同じ段の他のカードが短く見えていた)

### 狙い

実機報告: 本番のコンテンツ一覧で、カードの大きさが揃っていない。1 段目 (絶もうひとつの未来・異聞商客物語・ヘビー級) だけ他の段より高く、その段の異聞商客物語だけが隣の 2 枚より短い。

原因は 2 つ重なっていた。

- 2026-04-29 に、利用者の要望でカードの高さを固定した (右の列のバッジは無いときも `invisible` の空のバッジで場所を取る)。2026-09-08 (UI-2) に中央の列へ足した進行のスパークラインは、練習日が 2 日未満だと何も描かず、場所も取らなかった。「中央の列は可変高なので揃えなくてよい」という前提だったが、カードの高さはこの中央の列で決まるので、スパークラインのあるカードだけ 24px 高くなった
- 段 (`li`) はグリッドで一番高いカードの高さまで伸びるが、中の Card は伸びない (`h-full` が無い) ので、同じ段の短いカードは短いままだった

デモでの実測 (1024px 幅・3 列): スパークラインのあるヘビー級は中央の列 85px・カード 222px、同じ段の 2 枚は中央の列 61px・カード 198px (段は 222px)、他の段は 198px。

### 実装

- `components/portal/progress-sparkline.tsx`: 2 日未満のときに `null` を返すのをやめ、同じ組み (同じ大きさの svg + 11px の文字) の空の枠を `invisible` で置く (`SparklinePlaceholder`、`aria-hidden`)。文字の行の高さまで本物と一致させるため、高さを数字で決め打ちしない
- `app/(portal)/category/category-list.tsx`: Card に `h-full` を足して `li` の高さに合わせる (名前の折り返しなどで高さが違っても、同じ段のカードは揃う)。スパークラインの場所についてのコメントを直した
- 触っていない: 右の列のバッジ、アイコンの並び、カードの中身の配置

### 検証

- 手元の dev (デモの DB・admin の表示) で、コンテンツ一覧のカードを `getBoundingClientRect` で測った。7 枚すべて、中央の列 85px・カード 251px・段 251px で揃った (スパークラインのある 1 枚も、空の枠の 6 枚も同じ)。3 列 (1024px)・2 列 (800px / 660px)・1 列 (375px) のどれでも揃い、横スクロールは無い
- 反証の対照: 空の枠だけを一時的に `null` に戻すと、1 段目 251px・他の段 227px と 24px ずれた (測り方がずれを見分けられることの確認)。このとき 1 段目の 3 枚は `h-full` で 251px に揃っていた (直す前は 2 枚が短いままだった)。確認の後に空の枠へ戻した
- `tsc` / `eslint` (エラー 0) / `scripts/check-*.mjs` (94 本) が通る

### 動作影響 / トレードオフ

- スパークラインの無いカードにも、名前と `/slug` の下に 24px の空きができる。すべてのカードの高さが、スパークラインのあるカードに揃う
