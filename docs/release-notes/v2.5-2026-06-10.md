## 🔗 PR — TODO #73 クローズ: FFLogs 連携 native 拡張 (status='DECISION' な native session に auto-link)

**経緯**: TODO #2 で native スケジュール基盤を実装した時点で意図的に切り離していた FFLogs auto-link 経路 (TODO #2 → TODO #73 として 2026-05-08 分離) を埋める。従来は `linkReportsToSessions()` が `schedule_past_sessions` (sync 専用) 直読みで、native mode の確定済 sessions には FFLogs アイコンが一切出ない状態だった。

**設計判断 (ユーザー確認済、2026-06-10)**:
- **D1 = 別テーブル新設**: `native_schedule_session_logs` を新規作成 (sync 側 `schedule_past_session_logs` と並列構造)。FK ターゲットは `native_schedule_sessions.id` (UUID PK)、sync の `raw_date` PK 経由とは別経路。RLS / FK / スキーマを明確分離して polymorphic FK の複雑性を避ける
- **D5 = auto-link のみ実装**: manual 追加 / 削除 UI は本 TODO スコープ外 (sync 側も未実装なので native だけ先行しない)

**変更内容**:
- **新規 schema** [supabase/schema.sql](supabase/schema.sql) Section 5f: `native_schedule_session_logs` (id PK, native_session_id UUID FK ON DELETE CASCADE, url, source CHECK('auto'|'manual'), created_at, UNIQUE(native_session_id, url))。Section 7 RLS ループ / Section 7b REPLICA IDENTITY FULL / Section 8 Realtime publication にも追加
- **編集** [src/lib/server/fflogs.ts](src/lib/server/fflogs.ts):
  - `FflogsLinkResult` 型に `nativeSessionsScanned` / `nativeSessionsMatched` を追加
  - cleanup 段階 (sync が source='auto' を wipe する箇所) に native も並列で参加 → 再 sync で重複 / 古い結果を残さない
  - 共通 helper `MatchingSession<T>` 型 + `matchReportsToSessions<T>()` (同 JST 日マッチ + 時間差スコア greedy 1:1 ペアリング) を抽出。1.9.24 由来の挙動を完全踏襲したまま sync/native 両 wrapper で共有
  - 共通 helper `buildSessionLinkDetail<T>()` で result panel の detail 整形を共通化
  - `linkReportsToSessions()` を helper 経由に refactor (内部実装変更のみ、外部 API は完全互換)
  - `linkReportsToNativeSessions()` を新規追加: native_schedule_sessions WHERE status='DECISION' → 既存 native_session_id の auto/manual 行を除外 → 共通 matcher → native_schedule_session_logs に source='auto' INSERT
  - `linkFflogsReportsToVideos()` の Promise.all を 3 並列化 (video + sync session + native session)、戻り値に native フィールドと details 連結を追加
  - `fetchNativeSessionLogsByDate()` を新規追加: `native_schedule_session_logs` を `native_schedule_sessions!inner(raw_date)` JOIN で SELECT、sync 版と同じ shape (`rawDate → SessionLogEntry[]`) を返す
- **編集** [src/app/(portal)/page.tsx](src/app/(portal)/page.tsx): native ブランチの Promise.all に `fetchNativeSessionLogsByDate()` を追加、`SchedulePageBody` に prop drill (sync 経路の `fetchSessionLogsByDate()` と完全対称)。`sessionLogsByDate={{}}` (TODO #73 で空だった) を `sessionLogsByDate={nativeSessionLogsByDate}` に差し替え
