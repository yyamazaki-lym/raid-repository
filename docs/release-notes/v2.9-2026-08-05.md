## 🔎 日付の右の空白を詰め + 「確定」を見つけやすく

出欠表の日付・時刻の右にあった空白を詰めて、日付から出欠欄までを近づけた。

日程欄には「メモ」「動画」「FFLogs」の 3 つのアイコン枠が、アイコンが無い行でも位置を揃えるために常に確保されていた。実際にはどの行もアイコンを持たない運用が多く、その場合は幅 68px ぶんがそのまま空白になっていた。今後は「表の中に 1 つでもアイコンがある場合だけ」枠を確保するようにしたので、アイコンが無ければ空白は出ず、ある場合は従来どおり縦に揃う。空いた幅は各メンバー列に配られる。

あわせて「確定」の視認性を上げた。20 行前後が並ぶと確定行が埋没して見つけにくいという指摘を受け、確定バッジの色と輪郭・発光を一段強め、確定行の背景の色づけも従来より濃くした (2.5 倍)。バッジの見た目は次回開催日カード / 予定表 / 自前作成式の切替ボタンの 3 箇所で共有するようにしたので、今後片方だけ古い見た目に取り残されることがなくなる。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。ローカル実機で日程列 304px → 249px (アイコン無しの表)、横スクロール時も固定列と行の背景色が完全一致することを実測。過去 (詳細) 表でも同様に空白が詰まることを確認。

## 📅 参加人数が増えても日付が見えるように + 表示文言の全体見直し

出欠表を横スクロールしたときに「日程」列が左端に残るようになった。

参加人数に上限はなく、メンバーを追加した分だけ表が横に伸びる。これまでは 9〜10 人以上になると画面幅に収まらず横スクロールになり、右に寄せた時点で日付が画面外に消えて「どの日の行を見ているか」が分からなくなっていた。今後は日付が常に左端に残るので人数が増えても行を追える (スマホ幅では日付欄が画面の大半を占めてしまうため、タブレット以上でのみ固定)。列幅やページ幅、人数の制限は変えていない。

あわせてサイト全体の表示文言を精査:
- 出欠の「○」が凡例で「参加可」と表示されず色も他と違っていた不具合を修正 (自前作成式で既定の記号を使っている場合)。凡例設定の「既定値」表示が実際の記号と違っていた点も修正
- 誤字・表記の統一 (「切替えて」→「切り替えて」、「報告ページ」→「レポートページ」、確認ダイアログの「?」、「取込」→「取り込み」、「〜済」→「〜済み」など)
- 画面上の用語をボタン名と一致させた (「カテゴリ」→「コンテンツ」、削除確認の「戦略 / Loot / 軽減」→「攻略情報 / ロット管理 / 軽減表」、案内文の存在しないボタン名を修正)
- 説明文が語の途中で不自然に改行・空白が入っていた箇所を解消 (28 箇所)
- 長いコンテンツ名やメンバー名、時刻表記が枠をはみ出したり途中で折り返さないように調整

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。ローカル実機 (390 / 834 / 1280px) で主要 5 ページ + 設定ダイアログの横はみ出し 0・凡例ラベル復活・日程列の固定を実測。
