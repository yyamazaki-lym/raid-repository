## 🛡 手入力した FFLogs ログが日次バッチで消えてしまう不具合を修正

過去日程に手動で紐づけた FFLogs レポート URL が、翌日以降の自動整理バッチで巻き添え削除されることがあった不具合を修正 (多角的レビューで検出)。

スケジュールソースの都合で確定済みの日付がいったん「候補日」に戻ると、日次のスナップショット整理がその日付の自動生成行を掃除する際、同じ日付に手入力した FFLogs ログまで一緒に消してしまうケースがあった。今後は手入力ログが紐づく日付は整理対象から除外し、手入力データを保全する (自動生成分の掃除は従来どおり)。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。整理ロジックが手入力ログ有りの日付をスキップするよう修正し、スナップショットの UPSERT が手動作成行の種別を上書きしないことも合わせて修正。

## ♿ アクセシビリティ改善 — フォームエラーの読み上げ・トグルの選択状態・入力欄の名前・確認モーダルのフォーカス管理

多角的レビューで見つかったアクセシビリティ (スクリーンリーダー / キーボード操作) の取り残しをまとめて改善。見た目は変わらない。

- **フォームエラーの読み上げ**: コンテンツ編集・画像編集ダイアログの入力エラーに `role="alert"` を付け、保存できない理由がスクリーンリーダーに伝わるようにした (リンク編集ダイアログと同じ扱いに統一)。
- **トグルの選択状態**: コンテンツ編集のステータス選択・既定タブ選択のボタンに `aria-pressed` を付け、どれが選択中かが色以外でも分かるようにした。
- **入力欄の名前**: 日付メモ popover の投稿者名・本文・FFLogs URL 入力欄にラベル (aria-label) を付与。
- **確認モーダル / 結果ポップアップのフォーカス管理**: メモ削除の確認モーダルに初期フォーカス移動・Tab のフォーカストラップ・閉じたら元に戻す挙動を追加。メンテナンス結果ポップアップに Escape で閉じる・開いた時に結果へフォーカス移動・閉じたら元に戻す挙動を追加。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。dev preview で (1) コンテンツ編集ダイアログのステータストグルをクリックすると aria-pressed が切り替わること、(2) 空のまま保存で role=alert の「名前を入力してください」が出ること、をコンソールエラー無しで確認。

## 🗓 時刻データの取り違え防止 — 不正時刻・片側欠けの拒否

スケジュール解析まわりの軽微な不正値ハンドリングを底上げ (実害は限定的だが正確性を向上)。

- **不正時刻のロールオーバー防止**: スケジュール表の時刻欄に「25:00」のような範囲外の時刻が入っていた場合、これまで静かに翌日など別の日時に繰り上がっていたのを、不正な時刻はその行を読み飛ばすようにした。
- **開始/終了の片側欠け拒否**: 自前作成式スケジュールの時刻更新で、開始と終了のどちらか一方だけが空になる状態を明示的に拒否 (通知本文で個別指定と既定値が混在するのを防ぐ)。通常の画面操作では従来どおり両方同時に更新されるため挙動変化なし。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。

## 🔒 セキュリティ多層防御の底上げ (内部) — CSRF / 取得サイズ上限 / 描画サニタイズ / 入力長 / OAuth / 権限明示

利用者の操作には影響しない内部的なセキュリティ強化を、多角的レビューの指摘に沿ってまとめて実施。いずれも「既にある防御を漏れている経路にも横展開する」性質の底上げ。

- FFLogs 連携解除の API に Origin 検証 (CSRF 対策) を追加 (サインアウトと同じ扱いに統一)。
- Google フォトのアルバム取得にレスポンスサイズ上限を追加 (他の外部取得経路と同じ扱いに統一)。
- 攻略リンクの外部リンク描画を安全な URL チェック (safeHref) 経由に統一 (動画一覧と同じ多層防御)。
- スケジュールのルール文 (top-text) 保存に文字数上限を追加 (マクロと同じ 8000 文字)。
- FFLogs OAuth の state 照合を定数時間比較に変更。
- 並び順採番の内部関数の実行権限を明示的に絞り込み (read-only なので実害なし・意図の明文化)。
- 予備のレート制限 (フォールバック経路) が飽和した際の全走査を頭打ちにする簡易 LRU を追加。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。schema (RPC 権限) は本番 / demo に自動デプロイ。

## ⚡ 動画一覧の再描画を軽量化 (内部)

見た目・操作は変えない内部的な最適化 (多角的レビューのパフォーマンス項目)。動画一覧で 1 枚のカードを再生・選択・お気に入り操作した際に全カードが再描画されていたのを、カードを memo 化 + コールバックを安定化して該当カードのみの更新に抑えた。加えて、リアルタイム更新 (他の人の追加・削除) のたびにスクロール用のタイマー群を張り直していた無駄を解消。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。dev preview で動画ページの選択モードに入り、各カードの選択トグルが独立に切り替わること (aria-pressed 反映)・コンソールエラー無しを確認。

## 🧭 設定 — 「全 logs URL クリア」を Danger Zone（全データ初期化の隣）へ移動

管理者向け設定ダイアログで、FFLogs 連携セクションにあった「全 logs URL クリア」ボタンを、末尾の Danger Zone（全データ初期化の区画）へ移動した。全 logs URL クリア・全データ初期化という破壊的なリセット操作を 1 箇所にまとめて見つけやすく / 誤操作しにくくする狙い。機能・確認ダイアログの挙動は不変で、置き場所のみの変更。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。dev preview (admin) で FFLogs セクションから当該ボタンが消え、Danger Zone に「全 logs URL クリア」→「全データ初期化」の順で並ぶこと・コンソールエラー無しを確認。

## 🧭 設定 — Danger Zone を折りたたみ式に

設定ダイアログ末尾の Danger Zone（全 logs URL クリア / 全データ初期化）を、既定で折りたたんだ状態にした。破壊的操作の誤操作防止と UI ノイズ削減が狙いで、見出しをクリックすると展開する（FFLogs の OAuth / Session Cookie 節と同じ折りたたみ方式）。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。dev preview (admin) で既定は「DANGER ZONE」見出しのみ表示 → クリックで 2 つのカードが展開・シェブロンが回転することをコンソールエラー無しで確認。
