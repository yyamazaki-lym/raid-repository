## 🛡 同日 Logs の二重取り込みを防止

実機報告「08/29 の Logs が 2 個取り込みになっている」への対応。日付に紐づいたログと動画に紐づいたログが別レポート (または同一レポートの URL 表記違い) として並ぶと、スケジュール行の Logs アイコンが 2 個になっていた。

- **同一レポートの表記揺れを同一視**: #fight=3 などのアンカーや ja. サブドメイン付きの URL も、レポートコードが同じなら同じ Logs として扱う (アイコンの候補表示・手動追加の重複チェックの両方)
- **手動追加のガード強化**: 日付のメモ popover / native の Logs 追加で、同じレポートを別表記で二重登録できないようにした
- **自動連動の競合防止**: 同日の動画に既に別レポートが紐づいている日には、日次同期がスケジュール側へ食い違う auto 行を追加しない。逆に動画側の自動紐づけは、日付に登録済みのレポートと同じものを同点候補の中で優先する

## 🧹 「重複 Logs を整理」ボタンを追加

既に二重になってしまった分を一括で掃除する手段。設定ダイアログの FFLogs Sync セクション、「FFLogs と動画を連動」の隣に追加した。

- **同一レポートの重複行** (表記揺れで複数行になったもの) は 1 行だけ残して削除 (手動登録 > 自動、次いで登録が古いものを優先して残す)
- **同日の動画と食い違う auto 行**は削除 (auto は次回同期で再生成できるうえ、同期側にも同じ競合ガードを入れたので再発しない)
- 手動登録同士で別レポートが並ぶなど**機械判断できない競合は削除せず一覧表示**し、日付のメモ popover から個別に削除できるよう案内する
