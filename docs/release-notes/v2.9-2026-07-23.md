## 🔧 「起動中」表示が通常アクセスでも一瞬出てしまう件を調整

サーバーは正常に動いているのに、ページを開くたびに「サーバーを起動しています…」が一瞬だけ表示されることがあった件を調整。

「起動待ちかどうか」の判定時間が短すぎた (0.6 秒) のが原因で、ログイン済みページの通常の表示準備 (認証確認など) でも超えてしまうことがあった。判定を 1.5 秒に緩め、本当にサーバーが起動中のときだけ表示されるように変更。

**検証**: npx tsc --noEmit / npx eslint / npm run build pass。Playwright E2E (cold/warm/除外/ループガード) 再実行で全パス。SW キャッシュはバージョンアップ (v1→v2) により各ブラウザで次回アクセス時に自動更新。
