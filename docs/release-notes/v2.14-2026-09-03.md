## 🖼 コンテンツ: 背景画像の「カードに映す位置」を指定できるように

「背景画像設定でカードに映す位置を指定できないか」への対応です。

カードは横長で、背景画像は**はみ出した分を切り取って**表示されます。これまでは中央固定だったので、縦長の画像だと出したい部分（顔など）が切れていました。

コンテンツ編集の背景画像欄に**カードと同じ形のプレビュー**を置き、そこを**クリック / ドラッグ**すると表示を寄せられます（上をクリック = 画像の上の方を表示）。横位置・縦位置のスライダーでの微調整と「中央に戻す」も付いています。指定はコンテンツごとに保存され、未指定は従来どおり中央です。

## 🎯 練習ログ: 絶をフェーズ単位のバーにし、見出しも列を揃えた

「絶の方も P 毎に線を引いて見やすくできるか（零式でいう層毎のようなもの）」「セッション振り返りの見出しの層・残 HP・CLEAR も揃えられるか」への対応です。

**絶のバーをフェーズで区切りました**。零式の層と同じ扱いで、到達度 = (突破したフェーズ数 + 今のフェーズの削り) ÷ フェーズ数 になります。フェーズ数は実データで到達できた最深フェーズから決まるので、新しいフェーズに初到達した日に分母が増えます（層と同じ挙動です）。

あわせて**残 HP% を「最深フェーズ内」で見るように直しました**。FFLogs の残 HP% は到達したフェーズのボスの残 HP なので、フェーズを跨いで最小値を採ると「P1 で 0.5% まで削った」が「P7 で 30%」に勝ってしまい、バーが**進むほど短くなる**ことがありました。実データ相当の値で試すと、従来は 88% → 45% → 10% → 40% → 98% と行き来していたのが、フェーズ単位では 17.6% → 29% → 42% → 88% → 99.6% と素直に伸びます。

**見出しの列を揃えました**。日付の表記が日によって長さが違うため、日付欄に余りを吸わせ、pull 数・戦闘時間・死亡数・層/フェーズ・結果を固定幅にしました。絶にも層と同じ位置に **P1-P7 のようなチップ**が付き、フェーズは P1〜P7 で色分けされます（総 pull の内訳・pull 行・到達度の右ラベルも同じ色です）。

## 📐 練習ログ: pull 一覧の列を揃え、時刻と戦闘時間を色分け

「もう少し綺麗に揃えられないか」「#回数・時刻・戦闘時間が見分けづらい」への対応です。

**列を揃えました**。層ラベル (1層〜4層後半) や残 HP% は文字数が変わるため、行ごとに後ろの列がずれていました。層・結果・PT DPS・死亡数・動画の各列に固定幅を持たせ、数値は右寄せにしたので、縦にまっすぐ並びます。値が無い pull もその日に 1 つでも値があれば幅だけ確保するので、途中の行で崩れません。動画やPT指標がその日に 1 つも無い場合は幅を取らないので、余白が増えることもありません。

**色分けしました**。3 つとも灰色系で区別しづらかったので、#回数 = シアン / 時刻 = グレー / 戦闘時間 = インディゴ にしました。残 HP% の熱量色 (赤〜橙〜黄) とは別の色相を選んでいるので、「値が悪いから色が付いている」と誤読しません。テーマを切り替えても同じ色です。

## 📊 練習ログ: 総 pull に層 / フェーズの内訳を表示

「総 pull」のタイルに、層ごと (零式) またはフェーズごと (絶) の pull 数を小さく並べました。零式は 1層〜4層後半まで層の識別色で、絶は P1〜 と討伐で分かれます。

数字はタイルの中に折り返して収まるようにしてあり、他のタイルの配置は変わりません。明細が直近分に打ち切られている大きなカテゴリでは、表示中の pull の内訳になります (タイルの注記どおり)。

## ⚔ 練習ログ: 各 pull に PT 合計 DPS と死亡数を表示

セッション振り返りの各 pull で、残 HP% の横に **PT 合計 DPS** と **死亡数** を出すようにしました。日付の見出しにはその日の死亡数の合計も並びます。

数値は FFLogs の Summary から **PT 全員分を合計したもの** で、個人ごとの DPS は取得も保存もしていません (これまでどおり、個人を序列化する表示はしない方針です)。

この 2 つは fights 本体とは別のクエリで取るため、**次回の「ログを同期」または日次同期以降に取り込んだ pull から** 表示されます。既存の pull は直近 14 日分が再取得の対象なので順に埋まり、それより古い pull は「URL から取り込む」で該当レポートを再取り込みすると埋まります。取得できなかった pull は何も表示しません。
